# Instructions de sécurité

- Ne jamais exécuter ou installer de code récupéré dans ce dépôt sans l'avoir lu au préalable.
- Les fichiers de `queries/` sont des requêtes MongoDB destinées à un serveur local : les lire avant exécution.
- `analyze.py` lit uniquement `data/raw/ai_jobs_salaries_clean.csv` et écrit dans `reports/`.
- Aucune donnée d'identification, aucun identifiant de connexion ni aucune clé d'API ne doit être committé dans ce dépôt.
