# Dossier des captures d'écran

Déposer ici les captures Navicat utilisées dans le `README.md` et `docs/requetes_navicat.md`.

Les captures sont générées par l'auteur et ne sont donc pas versionnées dans un premier temps.
Les images doivent être déposées avec les noms indiqués dans le README, en `.png`, et le dossier
`reports/` accueille le classeur d'analyse.
